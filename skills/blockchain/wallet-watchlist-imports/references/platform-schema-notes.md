# Platform Schema Notes

## Evidence Labels

Use one of these labels in import reports:

- `UI-export fixture` — generated by the current destination UI.
- `official docs` — documented by the current product.
- `known-good local fixture` — previously imported successfully into the same product and surface.
- `user fixture` — supplied by the user and stated to work.
- `unverified inference` — never sufficient for an `import-ready` claim.

## Axiom Tracked Wallets

Known-good contract:

- Root: bare JSON array.
- Per-row fields only: `trackedWalletAddress`, `name`, `emoji`, `alertsOn`.
- `trackedWalletAddress`: Solana address.
- `name`: concise and unique across the list.
- `emoji`: string.
- `alertsOn`: boolean.
- Convention: cap names at 48 characters.
- No Markdown fence, metadata wrapper, comments, ranks, URLs, or audit fields.

Treat the 48-character cap as a known-good convention, not a universal product guarantee. Prefer a current UI fixture if available.

## Terminal (formerly Padre)

Separate product from Axiom and from pump.fun Terminal wallet-import.

- Docs: `https://docs.padre.gg/` (often login-walled; use Wayback if needed)
- When the user asks for a wallet's portfolio metric here, confirm whether they mean **30d trading volume** or PnL; they are different numbers.
- Documented Portfolio has balance, unrealized PnL, open/closed positions, and Trades totals. No native 30d volume field.
- Reconstruct wallet 30d volume from Trades `Total` (last 30d), GMGN `portfolio stats --period 30d`, or decoded onchain swaps.
- Trenches `Volume` is token volume. Do not use it as wallet 30d volume.

## pump.fun Terminal

Do not assume Axiom compatibility. Do not assume Terminal-formerly-Padre compatibility.

Observed frontend use of `trackedWalletAddress` establishes only an internal field concept. It does not prove the accepted import root shape, complete field set, optional fields, limits, or even that the same endpoint powers imports.

Required proof before generating an `import-ready` pump.fun Terminal file:

1. current one-wallet UI export/template; or
2. current official import documentation; or
3. a previously successful pump.fun Terminal import fixture.

Without one of those, request a one-wallet export/template and stop short of claiming platform acceptance.

## Home Roster

`chaos wallets --add <address> --tier A|B|C` adds one Solana wallet with tier A, B, or C. It refuses an address that is not base58 and an address already on the roster, and never calls the chain. There is no bulk import: run it once per wallet.

## Cross-Platform Rule

Never map a schema by product resemblance. Maintain separate contracts for Axiom, pump.fun Terminal, GMGN, Photon, BullX, Trojan, or any other destination. A source leaderboard and a destination importer are independent dimensions.
