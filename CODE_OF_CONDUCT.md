# Code of conduct

Be direct, be factual, be civil. Argue about code and evidence, not about people.

Not acceptable: harassment, personal attacks, posting someone's private information, or spam. Maintainers may remove comments, close threads, or block accounts for it.

To report behaviour, open a GitHub issue titled "conduct". For anything sensitive, use the "Report a vulnerability" button on the repository's Security tab instead; that report is private and only the maintainer reads it.
